🛡️ Shadow DOM Isolation Proof

Notice this host webpage defines aggressive global CSS overrides: button { background: red !important; font-family: Courier !important; }.

Look at the floating chat bubble in the bottom right corner. Thanks to Shadow DOM encapsulation, the chatbot launcher and modal retain their custom typography, obsidian theme, and styling without any CSS leakage!
